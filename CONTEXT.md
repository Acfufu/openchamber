# OpenChamber

Shared web, desktop, VS Code, and mobile UI surfaces for OpenCode. This glossary
holds project-specific language; implementation lives in module docs.

## Language

### Repo Wiki

**Repo Wiki**:
An AI-generated architecture guide for one project: a catalog of pages that
explain how the codebase works, generated by reading the code. One Repo Wiki
per project; it is a derived artifact, never user-authored documentation.
_Avoid_: wiki (bare), docs, knowledge base, DeepWiki

**Wiki Catalog**:
The generated table of contents of a Repo Wiki; pages hang off it.
_Avoid_: TOC, outline, index

**Wiki Page**:
One generated entry of a Repo Wiki: Markdown prose (optionally with diagrams)
whose claims point at source locations in the project.
_Avoid_: article, entry, note

**Source Reference**:
A pointer from a claim in a Wiki Page to a location in the project's source.
_Avoid_: citation, link (bare)

**Generation Run**:
One execution that creates or refreshes a project's Repo Wiki.
_Avoid_: build, sync, job

**Stale**:
The project's current HEAD commit differs from the commit recorded when the
Repo Wiki was generated. Commit is the only staleness authority — a branch
name says nothing about content and is display metadata only.
_Avoid_: outdated, dirty, changed (bare)

**Thought Level**:
A Generation Run option selecting how much reasoning the model spends
before answering: off, low, medium, or high. Unset means the model's own
default behavior; a level the chosen model cannot honor exactly is
rejected, never silently reinterpreted.
_Avoid_: thinking (bare), reasoning level, reasoning effort, variant
