# Android Shell (Capacitor)

Native Capacitor 8 Android project for `com.openchamber.app`, tracked in git.
`MainActivity.java` is an empty `BridgeActivity`: all behavior comes from
Capacitor plugins plus the bundled mobile web UI — do not add app logic in Java.

## Generated — never hand-edit

Regenerated by `cap sync` / `capacitor update` from `packages/mobile`:

- `capacitor.settings.gradle`, `app/capacitor.build.gradle` (plugin wiring;
  plugin Android sources live in `node_modules`, not tracked)
- `app/src/main/assets/public` (web build), `capacitor-cordova-android-plugins/`
- `app/src/main/assets/capacitor.config.json`, `capacitor.plugins.json`,
  `res/xml/config.xml`

Web assets come from a `packages/web` build (rewritten to launch `MobileApp`)
and are copied in by `bun run sync` — never paste web files here.

## Hand-maintained

- `variables.gradle` — SDK levels (min 24, compile/target 35) and androidx versions.
- `app/build.gradle` — release signing and versionCode/versionName come from
  `OPENCHAMBER_ANDROID_*` env vars at build time; defaults are placeholders.
  `google-services.json` is optional (absent) — FCM wiring activates only if present.
- `AndroidManifest.xml` — each permission carries a why-comment (CAMERA: QR
  pairing; POST_NOTIFICATIONS: FCM on Android 13+; RECORD_AUDIO: WebView voice
  dictation). Keep those comments when changing permissions.
- `network_security_config.xml` — cleartext and user CAs allowed: LAN
  OpenChamber servers over plain http are a core feature.

## Build

Always build through package scripts from `packages/mobile`
(`bun run build:android:debug`, `bun run android:*`): `with-mobile-env.mjs`
pins JDK 21 and the Android SDK paths. See `packages/mobile/README.md` for
commands, toolchain setup, and troubleshooting.
